# 🇰🇷 우리 돈으로 얼마지?

해외 화폐로 표시된 금액을 즉시 원화로 바꿔주는 안드로이드 플로팅 오버레이 앱입니다.
어떤 앱 위에서든 떠 있으므로 화면을 보고 그대로 입력하기만 하면 됩니다.

## 설치

1. [Releases](../../releases)에서 최신 `wooridun-*.apk` 다운로드 후 설치
2. 첫 실행 시 뜨는 권한 요청을 허용합니다:
   - **다른 앱 위에 표시** (설정 → 앱 → 우리 돈으로 얼마지? → 다른 앱 위에 표시)
   - **알림 권한**

## 사용법

| 동작 | 방법 |
|---|---|
| 열기 / 닫기 | 화면의 파란 플로팅 버튼 탭 → 패널 ✕ |
| 통화 선택 | 🇺🇸 달러 · 🇯🇵 엔 · 🇨🇳 위안 · 🇮🇩 루피아 · 🇻🇳 동 칩 탭 |
| 순서 변경 | 통화 칩을 **길게 눌러** 이동 모드 → 다른 칩 탭하면 그 자리로 이동 |
| 금액 입력 | 현지 화폐 금액을 그대로 입력 (천 단위 쉼표 자동) |
| `K` / `M` 버튼 | 입력값에 ×1,000 / ×1,000,000 — `Rp 125K`, `¥ 3M`처럼 적힌 가격용 |
| 세금·가산세 | 5% 단위 칩 또는 직접 입력 (예: 호텔·서비스세 21%) |
| 초기화 | `금액 초기화` (입력만) / `전체 초기화` (통화·세율·K/M 포함) |
| 투명도 | 타이틀 옆 게이지로 패널 반투명 조절 (0~100, 10 단위) |
| 환율 갱신 | 앱 실행 시 + 매시 정각 자동. `↻ 지금 갱신`으로 즉시 가능 |
| 다크모드 | 패널 위 🌙 / ☀️ 토글 |
| 종료 | `■ 앱 종료`, 또는 플로팅 버튼을 끌어 화면 **상단/하단의 ✕ 존**에 놓기 |

입력한 금액·통화·세율·K/M·투명도·다크모드·통화 순서는 저장되어, 다음에 열었을 때 그대로 복원됩니다.

## 참고

- 환율: [fawazahmed0/currency-api] 자동 수집, 실패 시 오프라인 예비값 사용
- 결과 = 금액 × 배율(K/M) × 환율 × (1 + 세율%)
- 개인정보 수집 없음, 네트워크 통신은 환율 조회뿐
